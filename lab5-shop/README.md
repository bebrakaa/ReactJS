## 📚 О стандарте

**ГОСТ Р 52872-2019** "Интернет-ресурсы. Требования доступности для инвалидов по зрению" основан на международном стандарте **WCAG 2.0 (Web Content Accessibility Guidelines)**.

### Уровень АА включает:
- ✅ Все критерии уровня A (25 критериев)
- ✅ Дополнительные критерии уровня AA (13 критериев)
- **Итого: 38 критериев успеха**

### Принципы POUR:
1. **Perceivable** (Воспринимаемость) - информация должна быть доступна для восприятия
2. **Operable** (Управляемость) - интерфейс должен быть управляемым
3. **Understandable** (Понятность) - информация должна быть понятной
4. **Robust** (Надёжность) - контент должен корректно интерпретироваться

## ✅ Реализованные улучшения доступности

### 1. Семантический HTML (WCAG 1.3.1)
- ✅ Использование `<header>`, `<nav>`, `<main>`, `<footer>`, `<article>`, `<section>`
- ✅ Правильная структура заголовков `<h1>` - `<h6>`
- ✅ Семантические списки для навигации `<ul>` / `<li>`
- ✅ Связанные `<label>` и `<input>` в формах

### 2. Клавиатурная навигация (WCAG 2.1.1, 2.4.3, 2.4.7)
- ✅ Все интерактивные элементы доступны с клавиатуры
- ✅ Логический порядок табуляции
- ✅ Видимый фокус на всех элементах (outline)
- ✅ `Tab` / `Shift+Tab` для навигации
- ✅ `Enter` / `Space` для активации кнопок
- ✅ `Escape` для закрытия модальных окон

### 3. Контрастность цветов (WCAG 1.4.3)
- ✅ Минимум **4.5:1** для обычного текста
- ✅ Минимум **3:1** для крупного текста (18pt+)
- ✅ Проверены все цвета: текст, кнопки, ссылки, иконки

### 4. ARIA-атрибуты (WCAG 4.1.2)
- ✅ `aria-label` для иконок без текста
- ✅ `aria-current="page"` для активной страницы навигации
- ✅ `aria-live="polite"` для уведомлений
- ✅ `role="alert"` для сообщений об ошибках
- ✅ `aria-invalid` и `aria-describedby` для ошибок валидации
- ✅ `aria-expanded` для раскрывающихся элементов
- ✅ `aria-labelledby` для связи заголовков с контентом

### 5. Альтернативный текст (WCAG 1.1.1)
- ✅ Описательные `alt` для изображений товаров
- ✅ `alt=""` для декоративных изображений
- ✅ `aria-label` для иконок (корзина, пользователь, поиск)

### 6. Формы и валидация (WCAG 3.3.1, 3.3.2, 3.3.3)
- ✅ Все поля имеют связанные `<label>`
- ✅ Описательные сообщения об ошибках
- ✅ Подсказки по исправлению ошибок
- ✅ `aria-invalid="true"` для полей с ошибками
- ✅ `aria-describedby` для связи ошибок с полями

### 7. Skip Navigation (WCAG 2.4.1)
- ✅ Ссылка "Перейти к основному содержимому"
- ✅ Видна только при фокусе с клавиатуры
- ✅ Позволяет пропустить повторяющуюся навигацию

### 8. Заголовки страниц (WCAG 2.4.2)
- ✅ Уникальный `<title>` для каждой страницы
- ✅ Формат: "Название страницы - Название сайта"
- ✅ Обновляется при навигации

### 9. Язык страницы (WCAG 3.1.1)
- ✅ `<html lang="ru">` для русского языка
- ✅ Помогает скринридерам правильно произносить текст

### 10. Масштабирование (WCAG 1.4.4)
- ✅ Использование относительных единиц (`rem`, `em`)
- ✅ Текст масштабируется до 200% без потери функциональности
- ✅ Нет фиксированных размеров в `px` для текста

### 11. Предсказуемость (WCAG 3.2.3, 3.2.4)
- ✅ Единообразная навигация на всех страницах
- ✅ Одинаковые элементы имеют одинаковые названия
- ✅ Фокус не вызывает неожиданных изменений

### 12. Предотвращение ошибок (WCAG 3.3.4)
- ✅ Подтверждение перед удалением товара из корзины
- ✅ Подтверждение перед отменой заказа
- ✅ Возможность вернуться и исправить данные

## 🧪 Тестирование доступности

### Автоматическое тестирование

1. **axe DevTools** (расширение для браузера)
   - Установить из Chrome Web Store / Firefox Add-ons
   - Открыть DevTools → вкладка axe
   - Запустить сканирование

2. **WAVE** (Web Accessibility Evaluation Tool)
   - https://wave.webaim.org/
   - Вставить URL приложения
   - Проверить отчёт

3. **Lighthouse** (встроен в Chrome DevTools)
   - DevTools → Lighthouse
   - Выбрать "Accessibility"
   - Запустить аудит

### Ручное тестирование

1. **Клавиатурная навигация**
   ```
   Tab          - переход к следующему элементу
   Shift+Tab    - переход к предыдущему элементу
   Enter/Space  - активация кнопок и ссылок
   Escape       - закрытие модальных окон
   ```

2. **Скринридер**
   - Windows: NVDA (бесплатно)
   - macOS: VoiceOver (встроен)
   - Проверить, что весь контент озвучивается

3. **Масштабирование**
   - Ctrl/Cmd + Plus - увеличить до 200%
   - Проверить, что всё работает

4. **Контрастность**
   - Использовать инструмент проверки контраста
   - Минимум 4.5:1 для текста

## 🎨 Ключевые изменения в коде

### 1. Семантический HTML

**Было:**
```jsx
<div className="header">
  <div className="nav">...</div>
</div>
<div className="content">...</div>
```

**Стало:**
```jsx
<header className="header">
  <nav className="nav" aria-label="Основная навигация">...</nav>
</header>
<main id="main-content">...</main>
```

### 2. ARIA-атрибуты

**Было:**
```jsx
<a href="/cart">
  <ShoppingCart />
  {count > 0 && <span>{count}</span>}
</a>
```

**Стало:**
```jsx
<a href="/cart" aria-label={`Корзина, товаров: ${count}`}>
  <ShoppingCart aria-hidden="true" />
  {count > 0 && <span aria-label={`${count} товаров`}>{count}</span>}
</a>
```

### 3. Формы с валидацией

**Было:**
```jsx
<input type="email" placeholder="Email" />
{error && <span>{error}</span>}
```

**Стало:**
```jsx
<label htmlFor="email">Email</label>
<input
  id="email"
  type="email"
  aria-invalid={!!error}
  aria-describedby={error ? "email-error" : undefined}
/>
{error && (
  <span id="email-error" role="alert">
    {error}
  </span>
)}
```

### 4. Skip Navigation

```jsx
<a href="#main-content" className="skip-link">
  Перейти к основному содержимому
</a>
```

```css
.skip-link {
  position: absolute;
  top: -40px;
  left: 0;
  background: #2563eb;
  color: white;
  padding: 8px;
  z-index: 100;
}

.skip-link:focus {
  top: 0;
}
```

### 5. Заголовки страниц

```jsx
useEffect(() => {
  document.title = "Каталог товаров - Интернет-магазин";
}, []);
```
